# Diagnostics

`dandori check` finds all of these but E040, E050 and E051, which `dandori gen` finds for each platform
it writes for. An error stops `gen`, which then writes nothing; a warning (W) does not. Each diagnostic comes with a run that
gets there, and `--lang ja` gives the same in Japanese. `dandori explain <code>` says when one comes,
how to fix it, and the smallest `.flow` that gets it.

| Code | What it finds |
|---|---|
| E001 | a syntax error |
| E002 | a name that is not there: a type (a message or an enum the `.proto` does not have, or a message that has a field of a type from a file the `.proto` imports and that could not be read, too), a variable, a field, a rule or a task, a date the dates file does not have, a book, or a transfer the book does not have, or a parameter `timeout until` names that the task does not have (a unit the table of units does not have, or a tax that is neither incl_tax nor excl_tax, too), an enum an `import enum` reads that its `enums` file does not have; a field whose type is not there is said once, at the field's line, and not where the field is written; a name of an enum's value written where nothing says its type (a `let` with no type, the list a `for` goes through) that no enum the flow sees has, that two enums or more have, or, in a list, that no one enum has all of (the note says which enums have it and how to write the type); a word in a string's `{…}` that is not a variable; a name no line sets, whatever fields records have. A line that reads a variable set from a value with an error, or uses a declaration with one, says nothing more. A name that is not there, written on several lines, is said once, at the first: the note gives the lines of the others |
| E003 | types that do not match: a value that may be absent used as it is, `none` where it cannot go, a list of lists, a `{…}` or `[]` whose type cannot be told, a range on what is not a number, an ordered enum, a date or a time (an enum with no order among them), a range no value is in, a bound of a range whose unit is not of its type or that does not come to a whole number of it that fits 64 bits, a number written with a unit (`fee: 0.5%`) where its type is not known, where a type with no unit goes (`int`, `json`), with a unit not of its type, or that does not come to a whole number of its type's unit that fits 64 bits, a bound that is not a value of its enum, a bound of a range of dates or of times that is not a day or is a day there is not, an `offset` on a range of dates or one past 23:59, a record that contains itself, written in the `.flow` or made of a message of a `.proto`, a time (`now`, say) passed to a date of a dates file whose calendar says no UTC offset, a parameter `timeout until` waits until that is not a `timestamp`, a value a case's `held` gives an input that is none of its values (a number outside its range, say), an argument of an `http` task no description holds that no style writes (a list or a record that holds a list or a record, for the path, the query or a URL-encoded body), two arguments that put a value under one name in the query or in a URL-encoded body, enums declared at two places, even with the same names and values (one enum of one `enums` file is one type by every name it is read by; the note says where each is declared) |
| E004 | too many or too few arguments or outputs, a field left out of a `{…}` record |
| E005 | a rule, a dates file or a book that could not be read, or a rule that cannot be called: one that does not pass rulec's check, one that walks a list of elements (`elements`), which dandori does not pass a rule, or one with an input or an output that may be none (`T?`); for `connect`, one whose Connect service rulec says nothing of, or does not say what the service calls the values of an enum; a call of a rule with no outputs, an `enums` file of rulec's, whose enums are types in the flow and from which nothing is generated to call; a dates file that does not pass koyomi's check, and a book that does not pass chobo's (or one that is not there); a file an `import enum` reads that is a rule, or that rulec does not pass; a file that could not be read is said once, at the line of its `use`, and not where its names, or what is made from them, are written |
| E006 | a name declared twice (rules, dates files and books share the names of `use rule`, `use dates` and `use book`); one name for a rule and an API; a rule whose alias is a name the code dandori writes around it uses already (`rules`, `args`, `out`, `activity`, `handler`, `ctx`, and the others of the design's 1.15), two rules of one alias, a task and a rule's activity (`rule_<rule>`) of one name, the name of an `import enum` (and its `->` name) |
| E007 | a task's clauses that do not go together: two ways of calling, a `flow` task with another one or with an `image`, `form` on a call to an OpenAPI operation, a Connect error code that is not one, an HTTP error without its status or two errors of one status, a `key` or a `callback` the way of calling cannot have (an agent takes no `key`), an AWS service it does not know, `model` without an `agent`, an agent without the type of its answer or with declared errors, an answer its schema cannot say, a provider it does not know, enum values that differ only in case for Claude, an `event` task's parameters (but the time of its `timeout until`), calls, `retry` or `key`, or one that starts a case, `timeout until` on a task that neither waits for an event nor is a `callback`, on an `aws` callback, or with a `retry` that retries `timeout`, two `timeout`s, a `url` on a task that is neither an agent nor a decision task, or on Claude's, a `url` that is not http or https, an `effort` on a task that is not an agent or at a level its provider does not take; for a decision task (`jev`), an API it does not know, an answer the model cannot give (not an enum, a `bool` or a record of them), a record's field left unasked or asked twice, a meaning for a value the enum does not have, a `score` without the meaning of every level or with more than 10 on TypeSafe's API, a choice or a score of one value, the meanings of yes and no on a predicate of the Decisions API, `refusal` on the System One API or without `jev openai`, `failure` or a declared error as the refusal's error, `retry` on it, what only `true` or only `false` means, a confidence that goes into what is not a rate of whole steps, `confidence` without `jev` or with `failure` or a declared error, a yes or no floor of 0.5 or less, `retry` on the error of `confidence`, an error without its status, `key`, `effort`; for a task that runs an operation of a book, an operation the transfer does not have (hold, post or void of a transfer done at once, do of one that holds first), `key`, `refused as`, an error's `= …`; a rule's clauses that do not go together: `lambda` and `connect` together, a `connection` without `connect`, a `connect` that is not http:// or https://; `plaintext` where there is no URL of the task's own, a `rule` or a `use` to reach, `discloses` naming what is not a parameter, and an empty reason of either |
| E008 | a case declared wrong (its state an enum made from a `.proto` whose values are not the machine's states, too), or a task that does to a case what it cannot; for a case that follows a book's hold, an operation that does not fit it (hold `starts` it, post `sends post`, void `sends void`, and do moves no case), an `external` other than `expire`, `refused when` |
| E009 | a statement where it cannot be: a `yield` that is not the last line of the body of `let <name> = for …`, or such a `for` without one; `break`, `succeed`, a case's call or an event's wait in a round of `for … in parallel`; `succeed` in `on failure` or `on cancel`; a variable given a value both inside a round and outside; a rule called without `let` |
| E010 | a value that no arm of a `match` takes |
| E011 | an arm that can never be taken |
| E012 | a variable read where it may have no value yet |
| E013 | a task called on a case that has not started, or a case started twice |
| E014 | a value that can be outside the range where it goes: a rule's input, a task's parameter, a field of a record written out, an output; for a range of an ordered enum's values, a value the range does not let in; for a range of dates or of times, a value that can be a day or a moment outside it (`now` in the period the workflow runs in, too) |
| E015 | a task that runs another `.flow` and does not fit it: its parameters and the child's inputs, its answer and the child's outputs, its errors and the child's `fail`s (a child that cannot be read or does not pass the checks, and a flow that runs itself, too) |
| E016 | a task that does not fit the API description or the book it calls: an operation that is not there, a parameter it does not take or one it needs left out, a type, range or enum that differs, a field the answer may leave out that is not `T?`, a status or an exception it does not answer with, a `key` that is not its idempotency token, a method that streams; where the description says where a parameter goes and how it is written (`style`, `explode`), a value that cannot be written so, a name that is two of its parameters or two parameters that are one, a parameter written as `content` says, a header the HTTP client writes itself or `Cookie` as a header, a name a header or a cookie cannot have, an `Idempotency-Key` parameter of a task with `key`, a required header or cookie that is not passed or may be absent (and a description that cannot be read, a `.proto` without `url` that a `connect` task calls, or a method whose message has a type from a file that could not be read); for a task that runs an operation of a book, parameters other than what the operation takes (by name and type), an answer that is not the hold (a do answers nothing), an error that is not a reason the book refuses the operation with; a description that could not be read is said once, at the line of its `use`, and not at the tasks that call its operations or where what is made from them is written |
| E017 | a workflow that does not fit the service it implements (`implements`): a service the `.proto` does not have, or one of a description that is not a `.proto`; a workflow the service does not name, a method with none of dandori's options or more than one, a method that streams, no method or two that start a run, a field of the start's request or its response that is no input or output, an input or an output that is no field, or one of another type, an output that may be absent where its field cannot say so, a name of `fails` the flow never fails with or one it fails with that `fails` does not list, a method that sends an event or answers a callback naming no such task, sending a value the task does not read, or answering something, a method that asks where a run is and takes something or answers other than `dandori.v1.Status`, a file that uses dandori's options without importing them, a message of a file that could not be read ([Implement a service](services.md)) |
| E018 | a flow that uses rules, dates files or books (`use rule`, `use dates`, `use book`), run with the `dandori` binary alone, which holds no other language and reads none of them: said once, at the first of those declarations, with the same command to run as `ritsu dandori`; the exit code is 2 |
| E020 | the workflow can end with a case in a state that is not final (also when `on cancel` ends it as cancelled) |
| E021 | an event sent that every state refuses (for a book's hold, an operation the book refuses in every state) |
| E022 | an event sent that can be refused, with nothing to handle the refusal (for a book's hold, declare the reason the book refuses with in `errors`, and handle it with `on <reason> =>`; a hold expires on its own, so a post or a void after a hold may be refused with `expired`) |
| E023 | a `fed by` that does not read, that names something that holds no value, or that stands on a line other than an input or a field of a record (`ritsu check` compares the values: E207, W207, E208) |
| E030 | a call that changes the other side, retried without a `key` |
| E031 | what an Express workflow cannot do: a wait longer than five minutes, a callback, a nested execution, a call that changes the other side without a `key` |
| E040 | one run can grow too large for the platform: its history over the limit (25,000 events on Step Functions, 51,200 on Temporal, 3,000 operations on Lambda durable functions), or on Argo Workflows more than 10,000 nodes |
| E050 | what the platform needs is missing, or the platform cannot do it: on Step Functions, a way of calling or a `connection` (an agent's, a decision task's and a rule at its service's too), a nested execution's declared errors, a `timeout` over 60 seconds on `http`, `agent` and `jev`, a destination that is not HTTPS (a rule's service too); off Temporal, `on cancel`, `event` tasks, and a method of the service the workflow implements that asks where a run is; on Step Functions and Lambda durable functions, a called rule's `lambda` or `connect`, and a called date's `lambda`; on Step Functions, a book's `lambda`; on Lambda durable functions, a `timeout` on a function it invokes; on Argo, a way of calling or an `image`, a `workflow template`'s declared errors, `retry` on a `callback` task, `history encrypted` |
| E051 | a name W105 warns of, for a platform being written: a caller reads it, so the code does not rename it, and the run writes nothing, for that platform or another it names |
| E906 | a value marked secret sent to a party outside the project: a model's provider (OpenAI, Anthropic, or an Open Responses server not on this machine), the API of a decision model (Jev, OpenAI's Decisions API, or a server not on this machine), a host an `http` task names by its URL alone, an AWS service; unless the task says it `discloses` the parameter ([Secrets](secrets.md)) |
| W030 | a call that may change the other side, retried without a `key` |
| W032 | a decision task that sets or reads a confidence, and names a model that moves to another by itself: an alias of Jev (`jev-latest`, `jev-preview`), a name without a tag or with `:latest` on a server of the System One API, any model of OpenAI's Decisions API (it names no version) |
| W101 | an error nothing handles can fail the run with a case in a state that is not final (while `on failure` or `on cancel` settles cases, too) |
| W102 | an `on <refusal>` that can never happen |
| W103 | a task that starts a case without a `key` |
| W104 | a value whose range nothing says, where a range is (`now` in a workflow that says no period it runs in, and in `on failure` and `on cancel`, too) |
| W105 | a name a caller reads that the code of a platform cannot keep: two such names are one identifier there (`send_mail` and `sendMail` in Go; the message `shop.Line` and a record `shop_Line` in TypeScript, Python and Go), the code declares the name for a caller (`Transport` in Go, `WorkflowInput` in TypeScript and Python), or it is a reserved word. A name the code has for itself alone (`WorkflowType` in Go, `Array` in TypeScript, `str` in Python) is not one: the code gives its own another name. `gen` stops for that platform (E051) |
| W106 | a whole number without a unit, as a value or an end of a range of a rate counted in steps other than 1% (`rate[step 0.1%]`): it counts steps (`5` is 0.5%), and a reader cannot tell 5 steps from 5%. Written with `%` (`fee: 0.5%`), the generated code passes the same number |
| W107 | a loop whose rounds still change a variable past 64 rounds (a value passed back one variable a round, through more than 64 variables): the checks read that variable as every value put in it anywhere in the flow, and follow the others to the end |
| W901 | a value in the shape of a key (an AWS access key ID; a GitHub, Slack, Stripe, OpenAI, Anthropic or Google key or token; a Slack incoming webhook URL; a PEM private key) written in the `.flow`, in a string or a comment; the line that says `ritsu: test secret` is a value for tests |
| W902 | a URL a task calls over plain HTTP, to a host that is not this machine (an `http` task's URL, an agent's `url`, `use rule … connect`, the `url` of `use openapi` and `use proto`, an OpenAPI document's first server), unless `plaintext "<why>"` is written where the URL is |
| W904 | a value marked secret kept in the history of the workflow: an input or an output, the answer of a task, an argument of a call, the reason of a `fail`; unless the workflow says `history encrypted` |
