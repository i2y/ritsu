# 診断コード

E040 と E050 は `dandori build` がビルド先のプラットフォームについて出し、それ以外はすべて `dandori check` が出します。エラーがあるとビルドは止まり、警告（W）では止まりません。どの診断にもそこへ至る実行の例が付き、`--lang ja` を付ければ日本語で出ます。`dandori explain <コード>` は、いつ出るか、直し方、そのコードを出す最小の `.flow` を出します。
