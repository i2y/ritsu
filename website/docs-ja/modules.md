# モジュール

モジュールは `ritsu.mod` を持つディレクトリです。ほかのプロジェクトが、横のディレクトリか OCI のレジストリから足して、そのファイルを `@<名前>/…` のパスで読みます。ritsu のリポジトリから配るモジュールは、[モジュールの一覧](modules/list/)に、版、ファイルごとのページ、版のあいだの差とともに載せています。
