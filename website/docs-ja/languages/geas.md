# geas

ファイルの拡張子は `.geas` です。

**geas** は、プログラムについての主張を一つずつ、動いているプログラム（コマンドライン、HTTP のサービス、ブラウザのページ）に当てて確かめ、差分を渡せば、それがどの主張にかかわるかを答えます。OpenSpec の仕様を渡せば、同じ名前の主張で確かめていないシナリオを挙げます。

サービスが答えたあとで終わるジョブのように、あとで出る結果は、主張に書いた時間まで待って確かめます。

OpenAPI の文書のあるサービスなら、ターゲットに一行足すだけで、すべての答えのステータス、必須のヘッダー、メディアタイプ、本体を文書と突き合わせます。文書にない呼び出しは、何も走らせる前に止めます。

呼び出しは `get`、`post`、`put`、`patch`、`delete` の五つで、ヘッダーを送れて、サービスの答えを次の呼び出しに使えます。サービスが決めた番号は `keep body json ".id" as id` で持っておき、`{id}` が次の呼び出しのパスになります。`keep env` で読んだトークンはどこにも出ません。ジャーナルとベースラインにはこれらの値を `{id}`、`{token}` と書くので、実行ごとに変わらず、番号が変わってもドリフトは何も言いません。

geas の文書はリポジトリにあります：[README](https://github.com/i2y/ritsu/blob/main/crates/geas/README.ja.md)。
