# yuen

ファイルの拡張子は `.req` です。

**yuen** では、要件ごとに、どこから来たか、誰が受け持つか、何が満たし何が確かめるかを書きます。どのリンクも両端のハッシュで固定されます。OpenSpec の仕様の要件も、同じように固定します。

yuen の文書はリポジトリにあります：[README](https://github.com/i2y/ritsu/blob/main/crates/yuen/README.ja.md)、[リファレンス（英語）](https://github.com/i2y/ritsu/blob/main/crates/yuen/docs/reference.md)、[診断のコード](https://github.com/i2y/ritsu/blob/main/crates/yuen/docs/codes.ja.md)。
