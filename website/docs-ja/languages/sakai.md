# sakai

ファイルの拡張子は `.ctx` です。

**sakai** では、どのコンテキストがどのファイルを持ち、誰が誰に依存してよいかを地図に書きます。コンテキストのあいだをまたぐ参照を、ここにあるすべての言語のファイルと、サービスが契約として持つ OpenAPI と AsyncAPI の文書と、コードについて確かめます。帳簿の `use book` は数えません。ほかのコンテキストからは、帳簿の前に立つサービスを通して使うからです。

sakai の文書はリポジトリにあります：[README](https://github.com/i2y/ritsu/blob/main/crates/sakai/README.ja.md)、[リファレンス（英語）](https://github.com/i2y/ritsu/blob/main/crates/sakai/docs/reference.md)、[出力先（英語）](https://github.com/i2y/ritsu/blob/main/crates/sakai/docs/targets.md)、[診断のコード](https://github.com/i2y/ritsu/blob/main/crates/sakai/docs/codes.ja.md)。
