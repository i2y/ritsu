## 関数

関数は、エフェクトで三つに分かれます。total な関数は、宣言した範囲のどの入力にも答えます。実行時に確かめる関数には、検査が示せなかった場所があります。生成したコードはそこで値を確かめ、外れれば、その場所の失敗の種類（`rule` など）で失敗します。止まらないかもしれない関数は、再帰を持ちます。

### 実行時に確かめる関数

#### `精算する`（`settle`）

実行時に 2 か所を確かめ、`range` で失敗することがあります。見出しには `total` と書いてあります。成り立つかは、言語をまたぐ確かめの答え（`ritsu kaname doc` が尋ねます）で決まります。

金額は売り手へ入り、規則がその金額に付ける手数料は、売り手から決済の事業者へ出る。

```kn
fn 精算する(settle)(支払い(payment): 支払い) -> 精算 total
  description "金額は売り手へ入り、規則がその金額に付ける手数料は、売り手から決済の事業者へ出る"
  let 手数料 = カード手数料(金額: 支払い.金額, 海外: 支払い.海外).手数料
  精算 {
    入金: 台帳.入金.do(支払い: 支払い.番号, 売り手: 支払い.売り手, 金額: 支払い.金額),
    手数料: 台帳.決済手数料.do(支払い: 支払い.番号, 売り手: 支払い.売り手, 手数料: 手数料),
  }
```

失敗しうる場所：

- 21 行目（`range`）: この実行では、ritsu の X4 の答えがありません。
- 22 行目（`range`）: この実行では、ritsu の X4 の答えがありません。
