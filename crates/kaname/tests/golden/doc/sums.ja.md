## 関数

関数は、エフェクトで三つに分かれます。total な関数は、宣言した範囲のどの入力にも答えます。実行時に確かめる関数には、検査が示せなかった場所があります。生成したコードはそこで値を確かめ、外れれば、その場所の失敗の種類（`rule` など）で失敗します。止まらないかもしれない関数は、再帰を持ちます。

#### `次`（`next`）

total な関数です。宣言した範囲のどの入力にも答えます。見出しにエフェクトは書いてありません。kaname が推論したものです。

```kn
fn 次(next)(現在の注文(o): 注文, 届いたイベント(e): イベント) -> 遷移
  match 現在の注文
    下書き d =>
      match 届いたイベント
        確定する p =>
          if count(d.明細) = 0
            遷移.受け付けない { 理由: "空の注文は確定できない" }
          else
            遷移.移った { 注文: 注文.確定 { 明細: d.明細, 日: p.日 } }
        取り消す c => 遷移.移った { 注文: 注文.取り消し { 理由: c.理由 } }
        else => 遷移.受け付けない { 理由: "下書きは先に確定する" }
    確定 p =>
      match 届いたイベント
        支払う y =>
          if y.金額 = 合計(明細: p.明細)
            遷移.移った { 注文: 注文.支払い済み { 明細: p.明細, 金額: y.金額 } }
          else
            遷移.受け付けない { 理由: "金額が合計と違う" }
        確定する q => 遷移.移った { 注文: 注文.確定 { ..p, 日: q.日 } }
        取り消す c => 遷移.移った { 注文: 注文.取り消し { 理由: c.理由 } }
        戻す => 遷移.移った { 注文: 注文.下書き { 明細: p.明細 } }
    支払い済み, 取り消し => 遷移.受け付けない { 理由: "終わった注文" }
```
