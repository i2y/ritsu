### `どの明細にも配る`（`every_line_gets_a_share`）

返金が 0 より多ければ、どの明細にも何かを配る。

```kn
property どの明細にも配る(every_line_gets_a_share)(明細(lines): list[明細] count >=1 <=10, 返金(refund): money[USDc] range >=0USDc <=10_000_000USDc)
  description "返金が 0 より多ければ、どの明細にも何かを配る"
  when 返金 > 0USDc
  let 配分 = 按分する(明細: 明細, 返金: 返金)
  all(配分, 一件 => 一件 > 0USDc)
```

`when` の行は 1 本です。最後の式は `all(配分, 一件 => 一件 > 0USDc)` です。
