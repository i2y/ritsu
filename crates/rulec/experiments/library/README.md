# rulec-rules（種）

給与計算で毎年書き換わる規則を、`.rule` 一枚と、そこから生成した九言語のコードで配る。
rulec の表は検査を通ってから生成され、生成物のヘッダに元の規則のハッシュと、写した条文・文書の時点とハッシュが刻まれる。

**これは転記であり、転記の正しさは保証しない。** 出典（`source` 行）と時点（`asof`）と写しのハッシュがヘッダにあるので、使う前に出典と見比べること。
表が分かっている期間の外の日付を渡すと、生成物は「範囲の外です」と断る。黙って古い率で計算し続けることはしない。

## 規則

| 規則 | 決めるもの | 出典 | 分かっている期間 |
|---|---|---|---|
| `健康保険料.rule` | 標準報酬月額の等級、折半、端数 | 健康保険法 第40条（e-Gov）、協会けんぽ保険料額表の注記 | 等級表は 2016-04 から変わっていない |
| `協会けんぽ健康保険料.rule` | 支部と月分から健康保険料率を引き、上を準用。子ども・子育て支援金を別の額で | 協会けんぽ 令和8年度都道府県単位保険料率、東京支部の保険料額表 | 月分 2026-03 〜 2027-02 |
| `厚生年金保険料.rule` | 標準報酬月額の等級、折半、端数（料率は入力） | 厚生年金保険法 第20条（e-Gov）、日本年金機構 保険料額表 | 等級表の上限は 2027-09 から段階的に上がる |
| `一般の厚生年金保険料.rule` | 上を 18.3% で準用 | 厚生年金保険法 第81条（e-Gov） | 18.3% は 2017-09 から固定 |
| `雇用保険料.rule` | 労働者負担額。支払日の年度と事業の種類で料率を引く | 厚生労働省 令和7年度・令和8年度の雇用保険料率について | 支払日 2025-04-01 〜 2027-03-31 |

まだ無いもの: 源泉徴収税額表（所得税法 別表第二。345 行 × 8 列で、年分ごとに畳むと大きい）、住民税、労災保険。

## 使い方

```console
$ rulec check rules/            # 通らなければ何も生成しない
$ rulec gen rules/ --out generated/
$ rulec test generated/         # 九言語が参照評価器と同じ答えか
$ rulec api rules/協会けんぽ健康保険料.rule   # 呼び方（署名・範囲・列挙の綴り）
```

Release には言語ごとのアーカイブ（`rules-<tag>-<lang>.tar.gz`）と `SHA256SUMS` が付く。SQL は関数ではなく関係への問い合わせ、Wasm はモジュール一つ。呼び方は `rulec api` の目録どおりで、生成物を読まなくてよい。

## 更新の回し方

1. 週次の `outdated.yml` が e-Gov に改正を問い、引用箇所が変わるとき issue を立てる（何が変わるか、どの `source` 行を足すかまで書いてある）。
2. 法令に無い出典（協会けんぽ・厚労省・年金機構）は毎年 2〜3 月に人が取り直す。`sources/` の写しを差し替えるとハッシュが変わり、`rulec check` が E038 で止めるので、行を読み直して `rulec source pin` で固定し直す。
3. PR には `rulec diff rules/<x>.rule@origin/main rules/<x>.rule --fixtures … --format markdown --terse` の結果を貼る（件数と金額だけ。本番の記録の値は出ない）。
4. マージで `check.yml` が通り、タグを打つと `release.yml` が九言語のアーカイブを出す。

期間の入力（`月分`・`支払日`）の `range` の上端が、この表が分かっている最後の日である。次の年度の率が出たら、行と `range` を足して新しいタグを打つ。上端を過ぎた日付は生成物が断るので、更新を忘れると止まる。それが意図である。
