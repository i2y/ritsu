 どの行にも当てはまらない入力が 2 か所あります:
   割れ物ありが true、割れ物なしが true
   割れ物ありが false、割れ物なしが false
 当てはまらない例: 割れ物あり = true, 割れ物なし = true
 この組み合わせは、定義からは起こりません（`割れ物あり` は `any 注文.lines where fragile = true`、`割れ物なし` は `all 注文.lines where fragile = false`）。
 それでも行を求めるのは、`from` を読まない呼び出しには届くからです。NumPy・Rust・Go・Swift・Java・SQL・Wasm の生成コードは `from` を読まず、呼ぶ側が計算した値をそのまま受け取ります。
 ヒント: 起こらない組み合わせは、行を足さずに次の行で表から外せます:
   never 割れ物あり = true, 割れ物なし = true
   never 割れ物あり = false, 割れ物なし = false
 ヒント: 次の行を足し、`?` に答えを書いてください:
   | true | true | ? |
   | false | false | ? |
 行のセルは、表がすでに書いている境と、範囲の端だけで切ってあります。新しい境は決めていないので、このまま足せば穴は全部埋まります。行の答えは道具が決めるものではありません。規約か Excel か、いま動いている実装か、どれが出どころかを決めて、そこから書いてください。途中で答えが変わる行は、そこで分けてください。
