 当てはまらない例: 割れ物あり = true, 割れ物なし = true
 この組み合わせは、定義からは起こりません（`割れ物あり` は `any 注文.lines where fragile = true`、`割れ物なし` は `all 注文.lines where fragile = false`）。
 それでも行を求めるのは、`from` を読まない呼び出しには届くからです。NumPy・Rust・Go・Swift・Java・SQL・Wasm の生成コードは `from` を読まず、呼ぶ側が計算した値をそのまま受け取ります。
 ヒント: この入力に当てはまる行を足してください。
 足す行の形: `| true | true | 5USD |`。出力の値は表の一行目からコピーした仮の値で、正しい値とは限りません。規約か Excel か、いま動いている実装か、どれが出どころかを決めて、そこから書いてください。この一行で埋まるのは、いま出た入力の穴だけです。ほかにも抜けがあれば、次の入力が出ます。
