   |               ^^^^^^^^^ core_path, a name with no alias

 The functions of a prerequisites block are named by its identifier (the alias, or the name where there is none) in snake_case (both are `core_path`) with `_requires` and `_available` after it, which some languages then write in lowerCamelCase or PascalCase, so the generated code declares one function twice: in every language that writes them it does not compile, or one hides the other. Give one of the two another alias.
