 A value of an enum is written by its identifier (the alias, or the name where there is none) in PascalCase (both are `Basic`), which some languages then put in upper case or in lowerCamelCase, so one enum declares one value twice: in every language that writes the values by name (all but SQL and NumPy) it does not compile, or one hides the other. Give one of the two another alias.
