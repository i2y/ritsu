$ rulec check case2.rule   # define fee : money[JPY] = down(amount * 3%, 1JPY)  range

  --> case2.rule:7
  |
7 | define fee : money[JPY] = down(amount * 3%, 1JPY)  range
  |                                                    ^^^^^ この後に `>=` も `<=` もありません
  |
 範囲は `range >=<値> <=<値>` の形で、端を少なくとも一つ書きます。端の無い `range` は何も決めず、書きかけの行と見分けがつきません。
 ヒント: `range` の後に端（`>=` か `<=`）を書いてください。範囲を決めないなら、`range` を消してください。

$ rulec check case8.rule   # constraint amount * 3% <= 20_000JPY
エラー[E017]: `constraint` の形が違います
  --> case8.rule:7
  |
7 | constraint amount * 3% <= 20_000JPY
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ 両側に入力の名前を書いてください（片側だけは `+` で足せます）
  |
 形は `constraint <入力> <= <入力>` です。比較は `<=` `<` `>=` `>` の四つで、両側とも入力の名前です。片側だけは、入力を `+` で足した和にできます（`constraint 値引き + ポイント <= 小計`）。
 入力から計算した値（積、商、定数を含む式）の上限と下限は、入力どうしの関係ではありません。その値を計算する `define` に、受け付ける範囲として書いてください（`define 小計 : money[円] = 数量 * 単価  range <=10_000_000円`）。
