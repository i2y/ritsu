 A `from` path reads one value. Each element of `order.lines` has its own `category`, and the path does not say which one the input takes.
 Two ways read `category` of the elements. One asks of them: `from any order.lines where category = <value>` is true when some element has that value, `all` when every one does, and `count` counts the elements that do. The other walks them as a sequence: write `elements <name> from order.lines` with a field `from category`.
 If `order.lines` always holds one element, make `lines` a field that is not `repeated` in the contract, and the path reads it.
