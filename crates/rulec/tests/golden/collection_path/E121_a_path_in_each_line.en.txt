 A `from` path reads one value. Each element of `order.lines` has its own `unit.kind`, and the path does not say which one the input takes.
 To read `unit.kind` in the elements, walk them as a sequence: write `elements <name> from order.lines` with a field `from unit.kind`. `where` and `of` name one field of an element, so `any`, `all`, `count`, `sum`, `max` and `min` cannot read it.
 If `order.lines` always holds one element, make `lines` one object in the contract rather than an `array`, and the path reads it.
