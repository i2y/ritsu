 A `from` path reads one value. Each element of `order.lines` has its own `quantity`, and the path does not say which one the input takes.
 Two ways read `quantity` of the elements. One asks of them: `from any order.lines where quantity = <value>` is true when some element has that value, `all` when every one does, and `count` counts the elements that do. The other walks them as a sequence: write `elements <name> from order.lines` with a field `from quantity`.
 A number can be added up or compared over them too: `from sum order.lines of quantity`, `from max order.lines of quantity empty <value>`.
 If `order.lines` always holds one element, make `lines` one object in the contract rather than an `array`, and the path reads it.
