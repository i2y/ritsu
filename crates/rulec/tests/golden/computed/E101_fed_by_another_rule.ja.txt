 どの行にも当てはまらない入力が 5 か所あります:
   kind が goods、amount が 1_000_001JPY から 3_000_000JPY、authority_finance が false
   kind が goods, software のどれか、amount が 1JPY から 1_000_000JPY、authority_finance が true
   kind が goods, software のどれか、amount が 3_000_001JPY から 100_000_000JPY、authority_finance が false
   kind が capex、authority_finance が false
   kind が software、amount が 1_000_001JPY から 3_000_000JPY、authority_finance が true
 当てはまらない例: kind = goods, amount = 1JPY, authority_finance = true
 `authority_finance` は、ほかの規則の出力を受け取る入力です（`fed by`）。`fed by` は値の出どころを書くだけで、その規則に何を渡したかは書きません。そのため、この検査は `authority_finance` を、ほかの入力とは関係の無い値として読みます。出どころの規則がほかの入力から決める値として読ませるには、その規則を `apply` で取り込んでください。
 ヒント: 次の行を足し、`?` に答えを書いてください:
   | goods | >1_000_000JPY <=3_000_000JPY | false | ? | ? | ? |
   | goods, software | <=1_000_000JPY | true | ? | ? | ? |
   | goods, software | >3_000_000JPY | false | ? | ? | ? |
   | capex | - | false | ? | ? | ? |
   | software | >1_000_000JPY <=3_000_000JPY | true | ? | ? | ? |
 行のセルは、表がすでに書いている境と、範囲の端だけで切ってあります。新しい境は決めていないので、このまま足せば穴は全部埋まります。行の答えは道具が決めるものではありません。規約か Excel か、いま動いている実装か、どれが出どころかを決めて、そこから書いてください。途中で答えが変わる行は、そこで分けてください。
