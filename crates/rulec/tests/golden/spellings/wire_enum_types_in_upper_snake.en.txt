 PHP: the enums' types are `HttpCode` and `HTTPCode`, and PHP reads the names of classes and enums with case set aside, so one enum is declared twice: the file does not load.
 Java: an enum's type is nested in the rule's class, and javac writes the two to `StatusFee$HttpCode.class` and `StatusFee$HTTPCode.class`: on a file system that sets case aside (the default of macOS and Windows) the two files are one, and one of the types does not load.

 For a target you do not generate, leave it. For one you do, give one of the two an alias (`HTTPCode(<alias>)`).
