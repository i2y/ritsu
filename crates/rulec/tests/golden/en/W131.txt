 The function that counts the answers (`invoice_sampling_chances` in Python) runs the rule over every point of the random inputs and counts each answer. It is exact and never disagrees with the rule's function, but one call costs as many runs as there are points.
 If it is called often, narrow the ranges of the random inputs. In a rule that picks by weight, let only the `draw` line read the random input, and the function counts from the weights without running the points.
