 An input that makes the divisor zero: units = 0
 Dividing by zero has no answer, and the generated code would stop on that call. rulec passes a division only where the ranges show its divisor is never zero.
 Hint: narrow the ranges so that the divisor cannot be zero, divide by `max(units, 1)`, or put a table that picks another value when it is zero and divide by that table's output.
