警告[W121]: `code` は、Python・Connect の生成コードが自分で使う名前と同じになります
  --> tests/own_names/codeという規則.rule:1
  |
1 | rule code v1
  |      ^^^^ 規則の名前
  |
 Python: 標準のライブラリに `code` というモジュールがあり、規則のために書いたモジュールがその代わりに読まれるか、二つを読み分けられなくなります。
 Connect: 生成コードは `Code` を読み込みます。規則のクラスも `Code` なので、それに取って代わり、組めないか、答えを違えます。
 使わない生成先なら、このままで構いません。使うなら、別名を付けてください（`code(<別名>)`）。
