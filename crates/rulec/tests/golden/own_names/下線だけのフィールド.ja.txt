 Python: 要素のフィールドは `NamedTuple` の `Element` のフィールドになり、`NamedTuple` のフィールドの名前は `_` で始められません。生成した Python のファイルは読み込めません。
 Rust・Swift・Wasm: `_` は値を捨てるパターンで、フィールドの名前になりません。
 Go: `_` は空白の識別子で、その名前のフィールドには値を書くことも読むこともできません。
 Java: `_` は予約語です。
 Connect: サービスは Python のモジュールを動かすので、読み込めません。
 使わない生成先なら、このままで構いません。使うなら、別名を付けてください（`_(<別名>)`）。
