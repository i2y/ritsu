 Python: 出力が二つ以上ある規則の出力は `NamedTuple` の `Output` のフィールドになり、`NamedTuple` のフィールドの名前は `_` で始められません。生成した Python のファイルは読み込めません。
 Rust・Swift・Wasm: 出力が二つ以上ある規則の出力は構造体 `Output` のフィールドになり、`_` は値を捨てるパターンなので、フィールドの名前になりません。
 Go: 出力が二つ以上ある規則の出力は構造体 `Output` のフィールドになり、`_` は空白の識別子なので、その名前のフィールドには値を書くことも読むこともできません。
 Java: 出力が二つ以上ある規則の出力はレコード `Output` の成分になり、`_` は予約語です。
 Connect: サービスは Python のモジュールを動かすので、読み込めません。
 使わない生成先なら、このままで構いません。使うなら、別名を付けてください（`_(<別名>)`）。
