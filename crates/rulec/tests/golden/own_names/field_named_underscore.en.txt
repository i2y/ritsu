 Python: the fields of an element are the fields of `Element`, a `NamedTuple`, and a `NamedTuple` takes no field whose name starts with `_`, so the generated Python file does not load.
 Rust, Swift and Wasm: `_` is the pattern that binds nothing, and names no field.
 Go: `_` is the blank identifier: a field of that name can be neither written nor read.
 Java: `_` is a keyword.
 Connect: the service runs the Python module, which does not load.
 For a target you do not generate, leave it. For one you do, give it an alias (`_(<alias>)`).
