# approvals

A server of requests and approvals. The rules are written in ritsu's request language under
`project/`, ritsu generates the Go code and the contract files from them, and the framework
[ringi-server](https://github.com/i2y/ringi-server) serves them: the pages people use in a browser, and the API.

`ritsu ringi init` wrote these files as a start: two request types, one of them with a flow, a small
organization, a gate, a server and a worker. They are yours now: change them into your own rules.

## What is in it

| File | What it is |
|---|---|
| `project/purchase.ringi` | A request type: its form, its route of two stages, its deadlines, and scenarios that say what happens |
| `project/expense.ringi` | A request type with a flow: an expense claim, which the requester's manager approves and the flow `pay` pays back |
| `project/shared/company.ringi` | The shape of the organization: the positions and the kinds of team |
| `project/org/2026-04-01/` | The organization's data from that day: its teams, people and members, as CSV |
| `project/shared/office.cal` | The business days the deadlines count |
| `project/shared/company.gate` | Who may do what on the tickets |
| `project/shared/pay.flow` | The flow of the payment, which an expense claim starts once it is approved |
| `go/`, `requests/` | What ritsu generates from `project/` (do not edit them) |
| `generate.go` | The line `go generate` runs to generate them again |
| `approvals.go` | What the project gives the server: its request types, organization, gate and notifier |
| `gate.go` | Asks the generated gate what the server asks |
| `notify.go` | A notifier that writes each notice to the log |
| `flows.go` | What starts the flows on Temporal, and the workers that run them |
| `payments.go` | The tasks of the payment, which the project writes: these write to the log |
| `cmd/server/` | The server |
| `cmd/worker/` | The worker that runs the flows |
| `*_test.go` | The tests |

## Running it

The flows run on Temporal: start its dev server first, with the Temporal CLI's
`temporal server start-dev`. It listens on `localhost:7233`, where the server and the worker look
for it (`-temporal` gives them another address). Then run the worker and the server, each in a
terminal of its own:

```sh
go mod tidy
go run ./cmd/worker
go run ./cmd/server -dev-login
```

Open http://127.0.0.1:8080/pages/ in a browser and choose who you are. `s1201` (a member of the
staff of Sales Section 1) makes a purchase request; `s1101`, the section's manager, approves it,
then `s1001`, the head of the Sales Department. The notices go to the log. `-dev-login` checks no
one, so the server answers this computer only.

An expense claim goes to the requester's manager alone. Once it is approved, the server starts its
payment on Temporal, and the worker runs it with the tasks of `payments.go`, which write `paid` and
`told` to the worker's log where real ones would pay the requester and tell them.

## Changing the rules

Change the files of `project/`, then check them and generate the code again:

```sh
ritsu check project
go generate ./...
go test ./...
```

`ritsu check` runs each scenario and checks what the rules claim; `ritsu ringi simulate
project/purchase.ringi --every-requester` shows where each person's request goes. In CI, run the
line of `generate.go` with `--check`: it writes nothing, and fails when `go/` or `requests/` is not
what `project/` makes.

The organization's data is built into the program: a new version of it is a directory
`project/org/<the day it takes effect>/`, and the server reads it when it starts again. A server that
runs takes it without starting again, from a person whose sign-in gives them the role
`system_admin` (with `-dev-login`, chosen on its sign-in page). Check the data with
`ritsu check project`, put `org/` into a zip archive from `project/`, and upload the archive on the
page `/pages/admin/organization`:

```sh
cd project && zip -r ../org.zip org -x '*/.*'
```

The page shows what the new data changes, day by day, and imports it when you confirm. Add the same
version to `project/org/` too: a server started again imports the data built in only when it changed
since the server last imported it. Each import, and each switch of a version of a request type, is
kept in the record that `/pages/admin/records` shows.

## Tests

`go test ./...` runs four tests:

- `TestVectors` gives the server every vector ritsu wrote in `requests/vectors/` from the rules
  and the scenarios, and checks what it returns.
- `TestGate` checks `gate.go` on what only the gate decides: who sees a ticket they are not on, and
  who withdraws one; who may do each of the four operations of the administration, by role and by
  department; that a person the organization's version does not have, and a request type that names
  no owner, are of no one's department; and that a role the gate does not declare is left out.
- `TestPages` makes a request on the pages with the development sign-in, and approves it.
- `TestFlows` runs the payment of an approved expense claim on Temporal's dev server, with the
  workers of `cmd/worker`: the requester is paid once, and told. The dev server runs from the
  Temporal CLI that `TEMPORAL_CLI` names, else from the file the SDK keeps in the system's temporary
  directory (`temporal-cli-go-sdk-<version>`). The test downloads nothing: without the CLI, it prints
  `SKIP`.

## Running it for people

`go run ./cmd/server -h` lists every flag. The framework's
[guide for people who run a server](https://github.com/i2y/ringi-server/blob/main/docs/operations.md) has what to
prepare, the backups, how to raise the version and what to watch.

- **Where the tickets are kept**: `-db 'postgres://…'` keeps them in PostgreSQL, in the schema
  `ringi`, with the attachments. Without `-db`, they are kept in memory and lost when the server
  stops.
- **How people sign in**: through an OpenID Connect provider, with `-oidc-issuer`,
  `-oidc-client-id`, `-oidc-redirect-url https://<the server's host>/login/callback`, and the
  client's secret and the keys of the session cookies in the environment variables
  `RINGI_OIDC_CLIENT_SECRET` and `RINGI_SESSION_KEYS` (base64 of 32 random bytes each, the newest
  first). A person is the one in the organization's data with the email address the provider has
  verified. `-oidc-roles-claim` names the claim that lists a person's roles: without it no one has a
  role, so no one may do what the gate gives to one, such as `system_admin`. Where a proxy in front of
  the server signs people in instead, the server is made in Go, with `web.ProxyHeader`
  ([how](https://github.com/i2y/ringi-server/blob/main/docs/embedding.md)).
- **https**: `-tls-cert` and `-tls-key`, with `-addr` on the address people reach.
- **Temporal**: `-temporal <host:port>`, the same on the server and on each worker. Run the
  workers beside the server, as many as the flows need. The namespace and TLS are the client's
  options (`client.Options`) in `cmd/server/main.go` and `cmd/worker/main.go`.

With no flag of a sign-in, the person is the one the header `X-Person` names. The header and
`-dev-login` check no one, so the server takes them only on an address of its own computer, and
refuses a request a proxy forwarded. It does not start with them on an address other computers reach,
with `-tls-cert`, or where the provider's settings are.

## Adding a request type

Write `project/<name>.ringi` beside `purchase.ringi`, with the same `use` lines for the organization,
the calendar and the gate, then run `ritsu check project`, `go generate ./...` and `go test ./...`.
The new type's scenarios become vectors that `TestVectors` runs. A type that reads masters needs
their data built in too: add their directory to the `//go:embed project/org` line of
`approvals.go`. `gate.go` asks the gate by the action's name, so an action added to the gate needs
no change there; an attribute added to a principal or a resource needs its value in `gateStore`. The
generated `RolesOf` returns the roles the gate lets a Staff hold, so one added to the gate needs no
change either.

## Adding a flow

A flow is work that runs after a ticket ends or in a stage of it, such as a payment or an agent's
check: `use flow <name> from "shared/<name>.flow"` in the request type, and `launch` or `ask` it, as
`expense.ringi` launches `pay` once a claim is approved. `go generate ./...` writes its Go package
under `go/flows/`. `Flows` in `flows.go` reads the flows the request types use, so the server starts a
new one as it is; its worker goes in `Workers`, with the tasks the project writes for it (its
package's `OwnTasks`, as `Payments` are the payment's). An agent's step needs the keys of its agents'
providers where its worker runs. The framework's module that runs the flows is
[`github.com/i2y/ringi-server/temporal`](https://github.com/i2y/ringi-server/tree/main/temporal): its README says more.

// Package approvals runs the requests of project/ on the framework: the package ritsu generated
// from them (go/ and requests/, which go generate writes again), with the gate (gate.go) and a
// notifier that writes to the log (notify.go). cmd/server is the server.
//
// The flows run on Temporal (flows.go), with the tasks the project writes for them (payments.go):
// the server starts them, and cmd/worker runs them.
package approvals

import (
	"embed"
	"io/fs"
	"log/slog"

	server "github.com/i2y/ringi-server"
	"github.com/i2y/ringi-server/orgfiles"

	"example.com/acme/approvals/go/ticketkinds"
)

//go:embed requests/openapi.json requests/types requests/a2ui requests/mcp
var requests embed.FS

//go:embed project/org
var project embed.FS

// Package loads the generated package: the kinds of request, with the files of the contract the
// server reads, built into the program. The vectors are not built in: they are for the tests.
func Package() (*server.Package, error) {
	dir, err := fs.Sub(requests, "requests")
	if err != nil {
		return nil, err
	}
	return PackageFrom(dir)
}

// PackageFrom loads the generated package from dir, a directory laid out as requests/ is: the
// tests load it from the disk, where the vectors are.
func PackageFrom(dir fs.FS) (*server.Package, error) {
	return server.Load(ticketkinds.Contract, ticketkinds.Lang, ticketkinds.Kinds, dir)
}

// Organization reads the organization's data in project/org: a directory for each version, named
// by the day it takes effect.
func Organization() server.OrgSource {
	dir, err := fs.Sub(project, "project")
	if err != nil {
		panic(err)
	}
	return orgfiles.New(dir)
}

// Parts are what the project gives the server: its kinds, its organization, its gate and its
// notifier, which write what they have to say in log. cmd/server adds where the tickets are kept and
// how people sign in, from its flags. Once the server is made, Started gives the notifier the server.
func Parts(log *slog.Logger) (server.Config, error) {
	p, err := Package()
	if err != nil {
		return server.Config{}, err
	}
	return server.Config{
		Packages:     []*server.Package{p},
		Gate:         &Gate{Log: log},
		Organization: Organization(),
		Notifier:     &LogNotifier{Log: log, Lang: "en"},
	}, nil
}

// Started gives the parts of cfg that read the server the server made from cfg (by server.New, or
// in the function Serve calls once it is made): the notifier, which says each kind by its title.
func Started(cfg server.Config, srv *server.Server) {
	if n, ok := cfg.Notifier.(*LogNotifier); ok {
		n.Server = srv
	}
}

// Command server serves the requests of the project: the pages people use in a browser, and the
// API. Where it keeps the tickets and how people sign in come from its flags:
//
//	go run ./cmd/server -dev-login
//
// lets you choose who you are on a page, on this computer only (-addr stays on 127.0.0.1). Without
// -dev-login, the person is the one the header X-Person names, on this computer only too: neither
// checks anyone. With -oidc-issuer, -oidc-client-id and -oidc-redirect-url, the server signs people
// in with an OpenID Connect provider, and -oidc-roles-claim names the claim that lists their roles.
// -db keeps the tickets in PostgreSQL; without it, they are kept in memory and lost when the server
// stops. go run ./cmd/server -h lists every flag.
//
// The flows run on Temporal, at the address -temporal gives (localhost:7233, where Temporal's dev
// server listens, by default): the server starts them, and cmd/worker runs them. The server stops
// when it cannot reach Temporal, and warns in its log when no worker runs a flow.
package main

import (
	"context"
	"errors"
	"flag"
	"fmt"
	"log/slog"
	"os"
	"os/signal"
	"sync"
	"syscall"
	"time"

	"go.temporal.io/sdk/client"
	sdklog "go.temporal.io/sdk/log"

	server "github.com/i2y/ringi-server"
	"github.com/i2y/ringi-server/serve"

	"example.com/acme/approvals"
)

func main() {
	var flags serve.Flags
	flags.Register(flag.CommandLine)
	temporal := flag.String("temporal", "localhost:7233", "the address of the Temporal server the flows run on")
	flag.Parse()
	log := slog.New(slog.NewTextHandler(os.Stderr, nil))
	if err := run(flags, *temporal, log); err != nil {
		server.LogStop(log, "the server stopped", err)
		os.Exit(1)
	}
}

func run(flags serve.Flags, temporal string, log *slog.Logger) error {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()
	stores, err := serve.Open(ctx, flags, log)
	if err != nil {
		return err
	}
	defer stores.Close()
	cfg, err := approvals.Parts(log)
	if err != nil {
		return err
	}
	c, err := client.Dial(client.Options{HostPort: temporal, Logger: sdklog.NewStructuredLogger(log)})
	if err != nil {
		return fmt.Errorf("-temporal %s: %w", temporal, err)
	}
	defer c.Close()
	flows, err := approvals.Flows(c, cfg.Packages...)
	if err != nil {
		return err
	}
	cfg.Flows, cfg.Agents = flows, flows
	ctx, cancel := context.WithCancelCause(ctx)
	var running sync.WaitGroup
	err = stores.Serve(ctx, cfg, func(srv *server.Server) {
		approvals.Started(cfg, srv)
		// Beside the server, the worker that gives it the answers of the flows a stage asks (an
		// agent's step, a note): a worker that cannot go on stops the server.
		running.Go(func() { cancel(flows.Run(ctx, srv)) })
		running.Go(func() {
			ready, stop := context.WithTimeout(ctx, 30*time.Second)
			defer stop()
			if err := flows.CheckWorkers(ready); err != nil && ctx.Err() == nil {
				log.Warn("the flows wait for their workers: go run ./cmd/worker", "err", err)
			}
		})
	})
	cancel(nil)
	running.Wait()
	if cause := context.Cause(ctx); err == nil && !errors.Is(cause, context.Canceled) {
		err = cause
	}
	return err
}

// Command worker runs the flows of the project on Temporal: the payment of an approved expense
// claim (project/shared/pay.flow), with the tasks the project writes for it (Payments). Run it
// beside the server, on the same Temporal (-temporal, localhost:7233 by default):
//
//	go run ./cmd/worker
//
// The server starts the flows; they wait in Temporal until a worker runs them. It runs until it is
// told to stop.
package main

import (
	"flag"
	"fmt"
	"log/slog"
	"os"

	"go.temporal.io/sdk/client"
	sdklog "go.temporal.io/sdk/log"
	"go.temporal.io/sdk/worker"

	"example.com/acme/approvals"
)

func main() {
	address := flag.String("temporal", "localhost:7233", "the address of the Temporal server the flows run on")
	flag.Parse()
	log := slog.New(slog.NewTextHandler(os.Stderr, nil))
	if err := run(*address, log); err != nil {
		log.Error("the worker stopped", "err", err)
		os.Exit(1)
	}
}

func run(address string, log *slog.Logger) error {
	c, err := client.Dial(client.Options{HostPort: address, Logger: sdklog.NewStructuredLogger(log)})
	if err != nil {
		return fmt.Errorf("-temporal %s: %w", address, err)
	}
	defer c.Close()
	workers := approvals.Workers(c, log)
	for i, w := range workers {
		if err := w.Start(); err != nil {
			for _, started := range workers[:i] {
				started.Stop()
			}
			return err
		}
	}
	<-worker.InterruptCh()
	for _, w := range workers {
		w.Stop()
	}
	return nil
}

package approvals

import (
	"log/slog"

	"go.temporal.io/sdk/client"
	"go.temporal.io/sdk/worker"

	server "github.com/i2y/ringi-server"
	"github.com/i2y/ringi-server/temporal"

	"example.com/acme/approvals/go/flows/expense_payment"
)

// Flows makes what starts the flows of the kinds of request on Temporal, through c: the server's
// Flows and Agents (cmd/server). It reads the flows the kinds name from their descriptions in pkgs
// (temporal.FlowsOf): here the payment of an approved expense claim.
func Flows(c client.Client, pkgs ...*server.Package) (*temporal.Runner, error) {
	listed, err := temporal.FlowsOf(pkgs...)
	if err != nil {
		return nil, err
	}
	return temporal.New(c, temporal.Config{Flows: listed})
}

// Workers make the workers that run the flows on Temporal, through c, each with the tasks the
// project writes for its flow: the payment's are Payments. cmd/worker runs them. A flow added to a
// kind of request needs its worker here.
func Workers(c client.Client, log *slog.Logger) []worker.Worker {
	return []worker.Worker{
		expense_payment.NewWorker(c, Payments{Log: log}, nil, ""),
	}
}

// TestFlows runs the payment of an approved expense claim on Temporal's dev server, as cmd/server
// and cmd/worker run it: s1201 claims an expense, the manager approves it, the server starts the
// payment (Flows), and the worker runs it with the project's tasks (Workers, Payments): the
// requester is paid once, and told. The dev server runs from the Temporal CLI TEMPORAL_CLI names,
// else the one the SDK keeps in the system's temporary directory; the test never downloads it, and
// without it says SKIP.
func TestFlows(t *testing.T) {
	cli := os.Getenv("TEMPORAL_CLI")
	if cli == "" {
		cli = filepath.Join(os.TempDir(), "temporal-cli-go-sdk-"+sdktemporal.SDKVersion)
	}
	if _, err := os.Stat(cli); err != nil {
		t.Skipf("SKIP: no Temporal CLI at %s (TEMPORAL_CLI names one); the test does not download it", cli)
	}
	quiet := sdklog.NewStructuredLogger(slog.New(slog.NewTextHandler(io.Discard, nil)))
	dev, err := testsuite.StartDevServer(t.Context(), testsuite.DevServerOptions{
		ExistingPath: cli, LogLevel: "error", ClientOptions: &client.Options{Logger: quiet}, Stdout: io.Discard, Stderr: io.Discard,
	})
	if err != nil {
		t.Fatal(err)
	}
	defer dev.Stop()
	c := dev.Client()
	var log lockedBuffer
	logger := slog.New(slog.NewTextHandler(&log, nil))

	// What cmd/worker runs.
	for _, w := range Workers(c, logger) {
		if err := w.Start(); err != nil {
			t.Fatal(err)
		}
		defer w.Stop()
	}
	// What cmd/server runs, with the tickets in memory and the clock on monday.
	cfg, err := Parts(logger)
	if err != nil {
		t.Fatal(err)
	}
	flows, err := Flows(c, cfg.Packages...)
	if err != nil {
		t.Fatal(err)
	}
	cfg.Flows, cfg.Agents = flows, flows
	cfg.Store, cfg.Authenticator, cfg.Clock, cfg.Logger = memstore.New(), servertest.Header{}, servertest.NewClock(monday), logger
	srv, err := server.New(cfg)
	if err != nil {
		t.Fatal(err)
	}
	Started(cfg, srv)
	if err := srv.ImportOrganization(t.Context()); err != nil {
		t.Fatal(err)
	}
	ctx, cancel := context.WithCancel(context.Background())
	ran := make(chan error, 1)
	go func() { ran <- flows.Run(ctx, srv) }()
	defer func() {
		cancel()
		<-ran
	}()

	r := do(t, srv, "s1201", "submit_expense", "", `{"form":{"amount":4800,"purpose":"A taxi to a customer"}}`)
	var b struct {
		Ticket ticket `json:"ticket"`
	}
	if r.Outcome != server.OK || json.Unmarshal(r.Body, &b) != nil {
		t.Fatalf("the claim: %s %s %s", r.Outcome, r.Problem, r.Body)
	}
	id := b.Ticket.ID
	if r := do(t, srv, "s1101", "approve", id, `{"revision":`+string(b.Ticket.Revision)+`}`); r.Outcome != server.OK {
		t.Fatalf("the manager approves: %s %s %s", r.Outcome, r.Problem, r.Body)
	}
	// The things to do after the approval: the start of the payment.
	if _, err := srv.RunToDo(t.Context()); err != nil {
		t.Fatal(err)
	}
	told := "msg=told request=" + id + " "
	for end := time.Now().Add(time.Minute); !strings.Contains(log.String(), told); time.Sleep(50 * time.Millisecond) {
		if time.Now().After(end) {
			t.Fatalf("the requester was not told within a minute:\n%s", log.String())
		}
	}
	if n := strings.Count(log.String(), "msg=paid request="+id+" "); n != 1 || !strings.Contains(log.String(), "PAY-"+id) {
		t.Errorf("the requester was paid %d times:\n%s", n, log.String())
	}
	if tk := ticketOf(t, srv, "s1201", id); tk.Status != "approved" {
		t.Errorf("the claim after the approval: %+v", tk)
	}
}

// lockedBuffer is a log the server and the worker write to while the test reads it.
type lockedBuffer struct {
	mu sync.Mutex
	b  bytes.Buffer
}

func (l *lockedBuffer) Write(p []byte) (int, error) {
	l.mu.Lock()
	defer l.mu.Unlock()
	return l.b.Write(p)
}

func (l *lockedBuffer) String() string {
	l.mu.Lock()
	defer l.mu.Unlock()
	return l.b.String()
}

package approvals

import (
	"context"
	"errors"
	"log/slog"
	"slices"
	"sync"

	server "github.com/i2y/ringi-server"

	"example.com/acme/approvals/go/authz/company"
)

// Gate asks the gate ritsu generated from project/shared/company.gate (go/authz/company), with what
// the framework's question says. The gate's Requesters and Approvers are groups: the person is in
// them when the question lists them. An attribute added to a principal or a resource needs its
// value in gateStore; a role the gate lets a Staff hold is in the answer of the generated RolesOf,
// so one added to the gate needs no change here.
type Gate struct {
	// Log is where Gate says a role a sign-in gives that the gate does not declare: once for each
	// role, for the first hundred of them.
	Log *slog.Logger

	mu   sync.Mutex
	told map[string]bool
}

// gateRoles are the roles a Staff principal of project/shared/company.gate can hold, in the order
// the gate declares them: the generated package's RolesOf, asked by the principal's type in Cedar.
// The generated gate refuses a person with a role it does not declare, whatever they ask, so Allow
// leaves out a role the sign-in gives for something else (a claim of the provider, a header of the
// proxy).
func gateRoles() []string {
	return company.RolesOf("Staff")
}

// Allow asks the gate by the action's name, with the ID of each resource the framework knows: the
// ticket, its stage, its kind of request (the version the question is of), and the organization.
// The gate takes the one its action asks about. An action the gate does not declare is an error;
// the gate's other refusals are a no, a person it does not read (one with no primary team in the
// organization's version) among them.
func (g *Gate) Allow(_ context.Context, q server.Question) (bool, error) {
	ids := map[string]string{"Ticket": q.Ticket, "Stage": q.Ticket + "/" + q.Stage, "RequestType": q.Kind, "Organization": "organization"}
	store := gateStore{q: q, roles: g.roles(q.Person)}
	a := company.Authorize(store, company.Principal{Type: "Staff", ID: q.Person.ID}, q.Action, ids, q.Now)
	if a.Err != nil && a.Err.Kind == "action" {
		return false, errors.New(a.Err.Message)
	}
	return a.Err == nil && a.Allowed, nil
}

// roles answers the roles of the person the gate declares, in the order the sign-in gives them:
// staff when it gives none of them. A role left out is said in the log.
func (g *Gate) roles(p server.Person) []string {
	declared := gateRoles()
	var kept []string
	for _, r := range p.Roles {
		switch {
		case !slices.Contains(declared, r):
			g.leftOut(r, p.ID)
		case !slices.Contains(kept, r):
			kept = append(kept, r)
		}
	}
	if len(kept) == 0 {
		return []string{"staff"}
	}
	return kept
}

// leftOut says in the log that the gate does not declare role, the first time a sign-in gives it.
// It keeps the names of a hundred roles at the most, as the names come from outside.
func (g *Gate) leftOut(role, person string) {
	g.mu.Lock()
	defer g.mu.Unlock()
	if g.told[role] || len(g.told) >= 100 {
		return
	}
	if g.told == nil {
		g.told = map[string]bool{}
	}
	g.told[role] = true
	if g.Log != nil {
		g.Log.Warn("the gate does not declare a role the sign-in gives, and is asked without it", "role", role, "person", person)
	}
}

// gateStore is what the gate reads, from one question.
type gateStore struct {
	q     server.Question
	roles []string
}

// Staff answers the person as the gate reads them, or nil for one the organization's version does
// not have (no primary team in it): the gate refuses them whatever they ask, so that no one outside
// the organization is taken as one of a department. Their department is their team of the kind of
// the team that owns the request type, the first team of that kind at or above their primary team:
// a request type owned by a section, a department or a division is compared at its own level,
// whatever the organization calls its kinds of team. A question with no owner among the version's
// teams (one of the organization, or of a request type that names no owner or a team the version
// does not have) gives their primary team, which owns nothing of it.
func (s gateStore) Staff(id string) (*company.Staff, error) {
	kind := ""
	if owner, ok := teamIn(s.q.Org, s.q.Owner); ok {
		kind = owner.Kind
	}
	department := s.q.Org.TeamOf(id, kind)
	if department == "" {
		return nil, nil
	}
	st := &company.Staff{Department: department}
	if id == s.q.Person.ID {
		st.Roles = s.roles
		if slices.Contains(s.q.Requesters, id) {
			st.MemberOfRequesters = []string{"requesters"}
		}
		if slices.Contains(s.q.Approvers, id) {
			st.MemberOfApprovers = []string{"approvers"}
		}
	}
	return st, nil
}

func (s gateStore) Stage(string) (*company.Stage, error) {
	return &company.Stage{Requester: s.q.Requester, Requesters: "requesters", Approvers: "approvers", Owner: s.owner(), SelfApproval: s.q.SelfApproval}, nil
}

func (s gateStore) Ticket(string) (*company.Ticket, error) {
	return &company.Ticket{Requester: s.q.Requester, Requesters: "requesters", Owner: s.owner()}, nil
}

func (s gateStore) RequestType(string) (*company.RequestType, error) {
	return &company.RequestType{Owner: s.owner()}, nil
}

// owner answers the team that owns the request type. One that names no owner is owned by no team:
// the gate is given an ID that no team of the organization's version has, so that it is no one's
// department, and only a rule that reads no department (a system administrator's) allows anything
// of it.
func (s gateStore) owner() string {
	if s.q.Owner != "" {
		return s.q.Owner
	}
	id := "(no owner)"
	for {
		if _, ok := teamIn(s.q.Org, id); !ok {
			return id
		}
		id = "(" + id + ")"
	}
}

// teamIn answers the team of the version v with the ID id, and whether it has one.
func teamIn(v *server.OrgVersion, id string) (server.Team, bool) {
	if v != nil {
		for _, t := range v.Teams {
			if t.ID == id {
				return t, true
			}
		}
	}
	return server.Team{}, false
}

// LogNotifier writes each notice to the log, where a real one sends a mail or a chat message: the
// notice names the people to tell, with their addresses from the organization's data. It says the
// kind by its title in the language it writes in (Server.Title), with the language the title is in:
// the kind's title as its file writes it where it has none in that language. A real one writes to
// each person in their own language, and sends each key once: the framework calls it again with the
// same key after a failure it could not tell from a success.
type LogNotifier struct {
	// Server is the server whose kinds the notices are of; Started sets it once the server is made.
	Server *server.Server
	Log    *slog.Logger
	// Lang is the language the notices are written in; "en" when empty.
	Lang string
}

// Notify writes the notice.
func (n *LogNotifier) Notify(_ context.Context, x server.Notice) error {
	to := make([]string, 0, len(x.To))
	for _, r := range x.To {
		to = append(to, r.ID+" "+r.Email)
	}
	lang := n.Lang
	if lang == "" {
		lang = "en"
	}
	title, in := n.Server.Title(x.Kind, x.Version, lang)
	n.Log.Info("notice", "notice", x.Notice, "to", strings.Join(to, ", "), "kind", x.Kind, "title", title, "title_lang", in, "ticket", x.Ticket, "stage", x.Stage)
	return nil
}

func TestPages(t *testing.T) {

	srv := newServer(t, dev, &log)
	h, err := web.New(srv, web.Config{Require: dev.Require, LoginURL: dev.LoginURL, SignOut: devlogin.LogoutPath, Logger: slog.New(slog.NewTextHandler(&log, nil))})
	if err != nil {
		t.Fatal(err)
	}
	dev.Server = srv
	dev.Mount(h)
	signIn := func(person string) *servertest.Browser {
		b := &servertest.Browser{Handler: h}
		if w := b.Post(devlogin.LoginPath, url.Values{"person": {person}, "return_to": {"/pages/"}}); w.Code != http.StatusSeeOther {
			t.Fatalf("%s signs in: %d %s", person, w.Code, w.Body)

		t.Helper()
		w := b.Get(page)
		f, err := servertest.ReadForm(w.Body.Bytes())
		if w.Code != http.StatusOK || err != nil {
			t.Fatalf("the page %s: %d %v", page, w.Code, err)

			if err := f.Set(name, v); err != nil {
				t.Fatal(err)
			}
		}
		w, err = b.Press(f, button)
		if err != nil {
			t.Fatal(err)
		}
		if w.Code != http.StatusSeeOther {
			t.Fatalf("%s on %s: %d %.500s", button, page, w.Code, w.Body)
		}
		return w.Header().Get("Location")
	}
	card := press(signIn("s1201"), "/pages/requests/purchase/new?lang=en", "button.submit", map[string]string{
		"f.amount": "120000", "f.purpose": "A laptop for the new member of the section",
	})
	id, ok := strings.CutPrefix(card, "/pages/tickets/")
	id, _, _ = strings.Cut(id, "?")
	if !ok {
		t.Fatalf("the request went to %q", card)
	}
	// The things to do after the request: the notice to the manager, which notify.go writes to the
	// log.
	if _, err := srv.RunToDo(t.Context()); err != nil {
		t.Fatal(err)
	}
	if !strings.Contains(log.String(), "msg=notice") || !strings.Contains(log.String(), "s1101@example.com") {
		t.Errorf("no notice to the manager in the log:\n%s", log.String())
	}
	// The notice says the kind by its title in the language notify.go writes in.
	if title, in := srv.Title("purchase", 1, "en"); in != "en" || !strings.Contains(log.String(), title) || !strings.Contains(log.String(), "title_lang=en") {
		t.Errorf("the notice does not say the kind by its title in en (%q in %q):\n%s", title, in, log.String())
	}
	if again := press(signIn("s1101"), card, "button.approve", nil); again != card {

	}
}

package approvals

import (
	"context"
	"log/slog"
)

// Payments are the tasks of the payment flow (project/shared/pay.flow) the project writes. These
// write to the log, where real ones pay the requester through the accounts system and tell them.
// The flow says each is idempotent: Temporal may run one again after a failure it could not tell
// from a success, and a real one pays a request once.
type Payments struct{ Log *slog.Logger }

// PayRequester pays the requester the amount of the request, and answers the payment's reference.
func (p Payments) PayRequester(_ context.Context, args map[string]any) (any, error) {
	id, _ := args["request_id"].(string)
	p.Log.Info("paid", "request", id, "requester", args["requester"], "amount", args["amount"], "purpose", args["purpose"])
	return map[string]any{"reference": "PAY-" + id}, nil
}

// TellRequester tells the requester the text.
func (p Payments) TellRequester(_ context.Context, args map[string]any) (any, error) {
	p.Log.Info("told", "request", args["request_id"], "text", args["text"])
	return nil, nil
}

package approvals

import (
	"bytes"
	"encoding/json"
	"fmt"
	"log/slog"
	"strings"
	"testing"
	"time"

	server "github.com/i2y/ringi-server"
	"github.com/i2y/ringi-server/memstore"
	"github.com/i2y/ringi-server/servertest"
)

// monday is a business day of the office's calendar, at 10:00 in its time.
var monday = time.Date(2026, 11, 16, 10, 0, 0, 0, time.FixedZone("+09:00", 9*60*60))

// newServer makes the server cmd/server makes, with the parts of the project (Parts), a store in
// memory and a clock set to monday: sign says who sends each request, and the log goes to log.
func newServer(t *testing.T, sign server.Authenticator, log *bytes.Buffer) *server.Server {
	t.Helper()
	logger := slog.New(slog.NewTextHandler(log, nil))
	cfg, err := Parts(logger)
	if err != nil {
		t.Fatal(err)
	}
	cfg.Store, cfg.Authenticator, cfg.Clock, cfg.Logger = memstore.New(), sign, servertest.NewClock(monday), logger
	srv, err := server.New(cfg)
	if err != nil {
		t.Fatal(err)
	}
	Started(cfg, srv)
	if err := srv.ImportOrganization(t.Context()); err != nil {
		t.Fatal(err)
	}
	return srv
}

// do does an operation as a person, and answers the reply.
func do(t *testing.T, srv *server.Server, person, op, ticket, body string) server.Reply {
	t.Helper()
	key := person + "." + op + "." + ticket // the operation's idempotency key: visible ASCII
	r, err := srv.Do(t.Context(), server.Call{Operation: op, Person: server.Person{ID: person}, Ticket: ticket, Body: []byte(body), Key: key})
	if err != nil {
		t.Fatalf("%s does %s: %v", person, op, err)
	}
	return r
}

// ticket is what the tests read of a ticket.
type ticket struct {
	ID       string          `json:"id"`
	Status   string          `json:"status"`
	Stage    *string         `json:"stage"`
	Revision json.RawMessage `json:"revision"`
}

// ticketOf reads a ticket as a person who may see it.
func ticketOf(t *testing.T, srv *server.Server, person, id string) ticket {
	t.Helper()
	r := do(t, srv, person, "get_ticket", id, "")
	var b struct {
		Ticket ticket `json:"ticket"`
	}
	if r.Outcome != server.OK || json.Unmarshal(r.Body, &b) != nil {
		t.Fatalf("%s reads %s: %s %s %s", person, id, r.Outcome, r.Problem, r.Body)
	}
	return b.Ticket
}

// gateOrg is a version of an organization of two divisions, for the questions the tests ask the gate
// themselves: a division has departments, a department sections, and the section facilities a unit.
// Each team has one person, in_<the team>. kind gives the name the data uses for the kind of each
// team, from the team's place in the list and the kind the organization declares.
func gateOrg(kind func(place int, declared string) string) *server.OrgVersion {
	teams := []server.Team{
		{ID: "acme", Kind: "company"},
		{ID: "corporate", Kind: "division", Parent: "acme"},
		{ID: "product", Kind: "division", Parent: "acme"},
		{ID: "general_affairs", Kind: "department", Parent: "corporate"},
		{ID: "finance", Kind: "department", Parent: "corporate"},
		{ID: "engineering", Kind: "department", Parent: "product"},
		{ID: "front_desk", Kind: "section", Parent: "general_affairs"},
		{ID: "facilities", Kind: "section", Parent: "general_affairs"},
		{ID: "mail_room", Kind: "unit", Parent: "facilities"},
		{ID: "accounting", Kind: "section", Parent: "finance"},
		{ID: "web", Kind: "section", Parent: "engineering"},
	}
	v := &server.OrgVersion{Day: "2026-04-01"}
	for i, team := range teams {
		team.Name, team.Kind = team.ID, kind(i, team.Kind)
		v.Teams = append(v.Teams, team)
		join(v, "in_"+team.ID, team.ID)
	}
	return v
}

// join adds person to the version, with team their primary team.
func join(v *server.OrgVersion, person, team string) {
	v.People = append(v.People, server.OrgPerson{ID: person, Name: person})
	v.Members = append(v.Members, server.Member{Person: person, Team: team, Primary: true})
}

// asDeclared names each kind of team as the organization declares it.
func asDeclared(_ int, declared string) string { return declared }

// question is what the server asks the gate when person does action at monday, with org the version
// of the organization in effect: of the organization alone for the organization's operations; of
// purchase (version 1, owned by owner, none for "") for those of a request type; for a submit, of the
// person's own new ticket; else of the ticket T-1 of someone else, at its stage head.
func question(org *server.OrgVersion, person server.Person, action, owner string) server.Question {
	q := server.Question{Action: action, Person: person, Now: monday, Org: org}
	switch action {
	case "import_organization", "read_organization_audit":
		return q
	}
	q.Kind, q.Version, q.Owner = "purchase", 1, owner
	switch action {
	case "change_request_type", "read_audit":
	case "submit":
		q.Ticket, q.Requester, q.Requesters = "T-2", person.ID, []string{person.ID}
	default:
		q.Ticket, q.Stage, q.Requester, q.Requesters = "T-1", "head", "the_requester", []string{"the_requester"}
	}
	return q
}

// allows answers whether g allows q. An error of the gate fails the test.
func allows(t *testing.T, g *Gate, q server.Question) bool {
	t.Helper()
	ok, err := g.Allow(t.Context(), q)
	if err != nil {
		t.Fatalf("%s asks %s: %v", q.Person.ID, q.Action, err)
	}
	return ok
}

// TestGate checks the gate glue (gate.go) on what only the gate decides. Through the server: the
// department that owns the request type sees its tickets and another department does not, and the
// requester withdraws their request, which comes back to them. Asked as the server asks the gate, in
// an organization of the test's own (gateOrg): who may do each of the four operations of the
// administration, by role and by department; that a person the organization's version does not
// have, and a request type that names no owner, are of no one's department; that a person's
// department is found at the level of the team that owns the request type, whatever the organization
// calls its kinds of team; and that the roles of a sign-in the gate does not declare are left out.
func TestGate(t *testing.T) {
	t.Run("tickets", func(t *testing.T) {
		var log bytes.Buffer
		srv := newServer(t, servertest.Header{}, &log)
		r := do(t, srv, "s1201", "submit_purchase", "", `{"form":{"amount":30000,"purpose":"Books for the section"}}`)
		var b struct {
			Ticket ticket `json:"ticket"`
		}
		if r.Outcome != server.OK || json.Unmarshal(r.Body, &b) != nil {
			t.Fatalf("the request: %s %s %s", r.Outcome, r.Problem, r.Body)
		}
		id := b.Ticket.ID
		for person, want := range map[string]server.Outcome{
			"s1101": server.OK,       // the manager, who answers its first stage
			"g1201": server.OK,       // general affairs, the department that owns purchase
			"e1201": server.NotFound, // engineering, who is not on it
		} {
			if r := do(t, srv, person, "get_ticket", id, ""); r.Outcome != want {
				t.Errorf("%s reads the ticket: %s, want %s", person, r.Outcome, want)
			}
		}
		tk := ticketOf(t, srv, "s1201", id)
		if r := do(t, srv, "s1201", "withdraw", id, `{"revision":`+string(tk.Revision)+`}`); r.Outcome != server.OK {
			t.Fatalf("the requester withdraws: %s %s %s", r.Outcome, r.Problem, r.Body)
		}
		if tk := ticketOf(t, srv, "s1201", id); tk.Status != "with_requester" {
			t.Errorf("the ticket after the withdrawal: %s", tk.Status)
		}
	})

	t.Run("administration", func(t *testing.T) {
		org, g := gateOrg(asDeclared), &Gate{}
		// in_front_desk is of general_affairs, which owns purchase in the first of the two answers,
		// and not of engineering, which owns it in the second
		for _, c := range []struct {
			roles  []string
			action string
			want   [2]bool
		}{
			{nil, "submit", [2]bool{true, true}},
			{nil, "change_request_type", [2]bool{false, false}},
			{nil, "read_audit", [2]bool{false, false}},
			{nil, "import_organization", [2]bool{false, false}},
			{nil, "read_organization_audit", [2]bool{false, false}},
			{[]string{"workflow_admin"}, "change_request_type", [2]bool{true, false}},
			{[]string{"workflow_admin"}, "read_audit", [2]bool{true, false}},
			{[]string{"workflow_admin"}, "import_organization", [2]bool{false, false}},
			{[]string{"workflow_admin"}, "read_organization_audit", [2]bool{false, false}},
			{[]string{"system_admin"}, "change_request_type", [2]bool{true, true}},
			{[]string{"system_admin"}, "read_audit", [2]bool{true, true}},
			{[]string{"system_admin"}, "import_organization", [2]bool{true, true}},
			{[]string{"system_admin"}, "read_organization_audit", [2]bool{true, true}},
			{[]string{"auditor"}, "change_request_type", [2]bool{false, false}},
			{[]string{"auditor"}, "read_audit", [2]bool{true, true}},
			{[]string{"auditor"}, "import_organization", [2]bool{false, false}},
			{[]string{"auditor"}, "read_organization_audit", [2]bool{true, true}},
			{[]string{"auditor"}, "add_approver", [2]bool{false, false}},
		} {
			for i, owner := range []string{"general_affairs", "engineering"} {
				p := server.Person{ID: "in_front_desk", Roles: c.roles}
				if got := allows(t, g, question(org, p, c.action, owner)); got != c.want[i] {
					t.Errorf("%v: %s, purchase owned by %s: %v, want %v", c.roles, c.action, owner, got, c.want[i])
				}
			}
		}
	})

	t.Run("no one's department", func(t *testing.T) {
		// teams with the IDs gate.go would give a request type that names no owner, unless a team
		// had them
		org, g := gateOrg(asDeclared), &Gate{}
		for _, id := range []string{"(no owner)", "((no owner))"} {
			org.Teams = append(org.Teams, server.Team{ID: id, Name: id, Kind: "department", Parent: "corporate"})
			join(org, "in_"+id, id)
		}
		// someone the version does not have does nothing, whatever their roles, with an owner or none
		for _, roles := range [][]string{nil, {"workflow_admin"}, {"system_admin"}, {"auditor"}} {

			for _, owner := range []string{"", "general_affairs"} {
				for _, action := range []string{"submit", "see", "change_request_type", "read_audit", "import_organization", "read_organization_audit"} {
					if allows(t, g, question(org, p, action, owner)) {
						t.Errorf("someone_else %v: %s, purchase owned by %q: allowed", roles, action, owner)
					}
				}
			}
		}
		// purchase with no owner is of no one's department, the teams above among them: no
		// administrator of a department switches it or reads its record, a system administrator
		// does, and an auditor reads it
		for _, person := range []string{"in_front_desk", "in_(no owner)", "in_((no owner))"} {
			for _, c := range []struct {
				roles  []string
				action string
				want   bool
			}{
				{nil, "see", false},
				{[]string{"workflow_admin"}, "change_request_type", false},
				{[]string{"workflow_admin"}, "read_audit", false},
				{[]string{"system_admin"}, "change_request_type", true},

			"in_accounting":      {false, false, true},  // in a section of that department
