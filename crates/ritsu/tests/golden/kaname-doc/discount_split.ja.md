## 性質

性質は、引数が宣言した範囲に入り、`when` の行がどれも成り立つ入力なら、最後の式が `true` になるという主張です。`kaname check` は性質をベクタで確かめ、反例があれば E603 にします。示したと言えるのは、`--lean` が証明を受け付けたときだけです。このページは性質の中身を載せ、答えは載せません。

### `どの明細も項目を保つ`（`every_line_keeps_its_label`）

どの明細にも、その項目のまま、明細の順に値引きを一つずつ配る。

```kn
property どの明細も項目を保つ(every_line_keeps_its_label)(明細(lines): list[明細] count >=1 <=10, 値引き(discount): money[USDc] range >=0USDc <=10_000_000USDc)
  description "どの明細にも、その項目のまま、明細の順に値引きを一つずつ配る"
  map(按分する(明細: 明細, 値引き: 値引き), 一件 => 一件.項目) = map(明細, 一件 => 一件.項目)
```

`when` の行はありません。範囲に入るどの入力にも当てはまります。最後の式は `map(按分する(明細: 明細, 値引き: 値引き), 一件 => 一件.項目) = map(明細, 一件 => 一件.項目)` です。
