### total な関数

#### `重さの合計`（`weight_of`）

total な関数です。宣言した範囲のどの入力にも答えます。見出しにエフェクトは書いてありません。kaname が推論したものです。

```kn
fn 重さの合計(weight_of)(明細(lines): list[明細] count >=1 <=30) -> mass[oz]
  sum(明細, 一件 => 一件.重さ × 一件.数量)
```

#### `見積もる`（`quote`）

total な関数です。宣言した範囲のどの入力にも答えます。見出しに `total` と書いてあり、kaname がそれを確かめています。

Media Mail の小包にならないカートか、規則が持つ料金表の部分より重いカートには none。

```kn
fn 見積もる(quote)(明細(lines): list[明細] count >=1 <=30) -> money[USDc]? total
  description "Media Mail の小包にならないカートか、規則が持つ料金表の部分より重いカートには none"
  let 重さ = 重さの合計(明細: 明細)
  if 重さ <= 15lb
    メディアメール(重さ: 重さ, メディアだけ: all(明細, 一件 => 一件.メディア)).料金
  else
    none
```
