使い方

1. 依存に足します

ritsu mod add pricing /acme/pricing@1.1.0

2. 署名を確かめる行を ritsu.mod に足します

signature "/acme/" by matching "^https://github[.]com/acme/" issuer "https://token.actions.githubusercontent.com"

3. 取り出します

ritsu mod fetch

4. ワークフローや kaname のモジュールから呼びます

use rule order_total from "@pricing/rules/order_total.rule"

ファイルはリンクの # のあとに入れて運びます。ブラウザはそこをサーバーに送りません。

上げる前に

1. プロジェクトをこの版に上げます

ritsu mod get pricing@1.1.0
ritsu mod fetch

2. 自分のファイルが壊れないかを確かめます

ritsu check .

3. プルリクエストのために、自分のファイルに何が変わるかを見ます

ritsu mod report --base main --format markdown

このページが言うのは、モジュールが何を変えるかです。自分のプロジェクトが壊れるかは、自分の ritsu check が言います。新しい値は、自分の表の外に出ることがあります。
