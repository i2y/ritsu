Use it

1. Require it

ritsu mod add tax /acme/tax@1.1.0

2. Check its signature, in ritsu.mod

signature "/acme/" by matching "^https://github[.]com/acme/" issuer "https://token.actions.githubusercontent.com"

3. Fetch it

ritsu mod fetch

4. Call a rule from a workflow or a kaname module

use rule vat_rate from "@tax/rules/vat_rate.rule"

The files go in the link, after its #, which a browser does not send to a server.
