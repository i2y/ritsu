     1 | request 例(an__example) v1 "例"
  = The name of a kind of request begins the names of the files it is lowered to, and of the modules and packages of the code generated from them (`an__example_route`). Go reads no file whose name starts with `_`, and rustc warns of a module's name with two `_` in a row. Choose a name that starts with a letter, ends with a letter or a digit, and has no two `_` in a row.
