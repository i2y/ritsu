# 経費の申請

経費・出張・購買の申請。種別と金額に応じて、決裁権限規程（架空）第 12 条の別表 2 が定める役が、確かめ、承認し、決裁する

ファイル：`expense.ja.ringi`（申請の種類 `expense_ja` の版 1、sha256:6fcdf162a1b59902）

受け持つチーム：経理部（`accounting`）

組織は、置いてある版のそれぞれ（2026-04-01、2027-04-01 から）で読んでいます。

## 使える期間

- 2026-04-01 から使えます。決めているのは、組織 `shared/company.ringi` の最初の版（データ `../org`）です。
- 終わりの日はありません。読む物に終わりがありません。

## 出せる人

組織のだれでも出せます。

人数は、2026-04-01 からの組織の 24 人のうち 24 人、2027-04-01 からの 23 人のうち 23 人です。

代わりに出す代理の人は、代わる人の名前で出せます。その申請は、代わられた人の申請になります。

## フォーム

| フィールド | 型 | 受け付ける値 | 必須 | 表示 |
|---|---|---|---|---|
| 種別 | 出張、経費、購買のどれか | — | 必須 | いつも |
| 明細 | 明細の行 | 1行から20行まで | 必須 | いつも |
| 明細 › 品目 | 一行の文 | 100字まで | 必須 | いつも |
| 明細 › 金額 | 金額（円） | 1円から1,000,000円まで | 必須 | いつも |
| 合計 | 金額（円）。計算：「明細」の行の「金額」の合計 | 1円から10,000,000円まで（計算した値は1円から20,000,000円までになりえます） | 計算する | いつも |
| 目的 | 文 | 1字から200字まで | 必須 | いつも |
| 使った日 | 日付 | 2026-01-01から2027-12-31まで | 必須 | いつも |
| 行き先 | 一行の文 | 100字まで | 必須 | 「種別」が「出張」のとき |
| 領収書 | 添付ファイル | — | 「合計」が30,000円より大きいとき | いつも |
| 勘定科目 | `マスタ.accounts` の行 | — | 承認者が入れる | いつも |

> 空のフィールドは値を持ちません。任意のフィールド、条件つきで必須か表示のフィールド、承認者が入れるフィールド（入れるまで）がそうです。「〜でない」という条件は、値が無いときも成り立ちます。「〜である」という条件と大きさの比べは、値が無いときは成り立ちません。値の無いフィールドを読む計算も値を持ちません。合計は別で、セルが入っている行だけを足します。

計算するフィールドが受け付けるのは、書いた範囲の値です。計算した値が範囲の外になる申請は断られます。経路の表は、受け付ける値を覆えば足ります。

## 経路

経路は「種別」と「合計」で決まります。表の一行が一つの場合で、通るステップを順に並べています。各ステップにだれが答えるかは「承認者の決め方」にあります。

| 種別 | 合計 | 経路 |
|---|---|---|
| 出張 | 30,000円以下 | エージェント決裁（決裁） |
| 出張 | 30,000円より大きく、100,000円以下 | 上長（決裁） |
| 出張 | 100,000円より大きい | 上長（一次） → 部長（決裁） |
| 経費 | 100,000円以下 | エージェント確認（確かめ） → 上長（決裁） |
| 経費 | 100,000円より大きく、1,000,000円以下 | エージェント確認（確かめ） → 上長（一次） → 部長（決裁） |
| 経費 | 1,000,000円より大きい | 上長（一次） → 部長（二次） → 本部長（決裁） |
| 購買 | 1,000,000円以下 | 上長（一次） → 経理（二次） → 部長（決裁） |
| 購買 | 1,000,000円より大きい | 上長（一次） → 部長と経理（二次） → 本部長（決裁） |

## 承認者の決め方

| 承認者 | 決まる人 |
|---|---|
| 上長 | 申請者の上長。申請者が主に属するチームの長で、その長が申請者自身か空なら、上のチームの長です |
| 部長 | 申請者から上へたどって最初の、種類が `department` のチームの長 |
| 経理 | 経理部（`accounting`）の人。だれか一人が答えます |
| 本部長 | 申請者から上へチームの長をたどって、役職が `division_head` 以上の最初の人 |
| エージェント確認 | flow `事前の確かめ` のエージェントが答えます。確かでないときと失敗したときは、代わりに「上長」が答えます |
| エージェント決裁 | flow `出張の決裁` のエージェントが答えます。確かでないときと失敗したときは、代わりに「上長」が答えます |
| 取締役 | 取締役会（`board`）の人。だれか一人が答えます |

承認者は、ステップが始まるときに、そのときに効いている組織の版で決めます。その日に有効な代理も、並んで答えられます（「代理」を見てください）。

## 期限と催促

どのステップも：

- 期限は、始まった日から 3 営業日の日の終わりです。
- 始まった日から 2 営業日の日の 09:00 に、承認者へ催促が届きます。
- 期限を過ぎると表 `一段上` のとおりに上へ回ります。期限は、そこから数え直されます。また過ぎるとチケットは期限切れで終わります。
- 答える人がいなければ、上の長へ回ります。組織のいちばん上では、「取締役」へ回ります。

期限を過ぎたステップは、表 `一段上` のとおりに上へ回ります。

| 承認者 | 回す先 |
|---|---|
| エージェント確認 | 上長 |
| エージェント決裁 | 上長 |
| 上長 | 部長 |
| 部長 | 本部長 |
| 経理 | 本部長 |
| 本部長 | 本部長 |
| 取締役 | 取締役 |

2026-04-03（金）に始まるステップでは、次のとおりです。申請の種類のカレンダーの休みは数えません（時刻は UTC+09:00）。

| ステップ | 催促 | 期限 | 上へ回したあとの期限 |
|---|---|---|---|
| 確かめ | 2026-04-07（火）09:00 | 2026-04-08（水）の終わり | 2026-04-14（火）の終わり |
| 一次 | 2026-04-07（火）09:00 | 2026-04-08（水）の終わり | 2026-04-14（火）の終わり |
| 二次 | 2026-04-07（火）09:00 | 2026-04-08（水）の終わり | 2026-04-14（火）の終わり |
| 決裁 | 2026-04-07（火）09:00 | 2026-04-08（水）の終わり | 2026-04-14（火）の終わり |

チケットは、長くても 93 営業日で終わります（ステップに 4 × 21、申請者のもとで 3 × 3）。いちばん長い場合の日付は `ritsu ringi doc --longest` が見せます。

## チケットの決まり

- 申請者は、自分の申請を承認しません。どのステップの承認者からも外します。代わりに出した人も同じです。
- 一人の承認者が、すぐ前のステップを承認していれば、そのステップはその承認で済みます。
- 承認者は、申請者へ差し戻せます。取り下げと合わせて 3 回までです。使い切ったら、承認か却下を選びます。
- 申請者へ戻ったら、戻った日から 3 営業日の日の終わりまでに出し直せます。過ぎると期限切れで終わります。出し直しでは、変えるフィールドだけを渡します。
- 申請者は、ステップ「決裁」が答えるまで取り下げられます。取り下げたチケットは手元へ戻り、直して出し直すか、やめるかを選びます。
- 承認者は却下できます。チケットは却下で終わり、出し直せません。
- 申請の種類を受け持つチームは、今のステップに承認者を足せます。承認者の一人の受け持ちを、ほかの人に引き継ぐこともできます。どちらも期限を動かしません。

## コメント

- 人がする操作（申請、承認、差し戻し、却下、取り下げなど）には、コメントを一つ添えられます。コメントだけを書くこともできます。添えなくてもかまいません。
- だれが書けるかは、ほかの操作と同じく、gate `shared/company.gate` が決めます。
- コメントは 2000 字までです。チケットの履歴の、その人がしたことの行に、書いた人と時刻と一緒に残り、あとから変えません。コメントだけを書いても、チケットの状態と期限は変わりません。
- 理由を書かずに却下も差し戻しもできますが、書けば、申請者は何を直せばよいかを履歴で読めます。

## 代理

- 承認の代理は、行の期間のあいだ、代わる人のステップに並んで答えます。答えは、代わる人の席で一票に数えます。保留と再開、承認者が直すフィールドの直し、自分がした承認の取り消しもできます。
- 申請の代理は、代わる人の名前で申請を出します。取り下げ、出し直し、やめることも、申請者と同じくできます。
- 代理がしたことは、だれの代わりにしたかと一緒に、履歴に残ります。

## 帳簿と flow

- 出したとき、申請者の上に種類が `department` のチームがあるなら、帳簿に `予算.reserve` の仮押さえが入ります（`amount` に「合計」）。
- 承認されたとき、仮押さえ `予算.reserve` が確定します。
- 承認されたとき、flow `支払い` が始まります（`amount` に「合計」、`purpose` に「目的」）。
- 差し戻されたか、却下されたか、取り下げられたか、期限切れになったとき、仮押さえ `予算.reserve` が取り消されます。

## 主張

検査は、どれも成り立つことを確かめています。成り立たない主張があれば、この申請の種類は検査を通りません。

- `エージェントが決裁するのは3万円まで`：ステップ「決裁」が「エージェント決裁」になるのは、「合計」が30,000円以下のときだけです。
- `二次承認を部長と経理でする場合がある`：ステップ「二次」が「部長と経理」になる申請があります。
- `催促は期限より前`：どのステップも、期限の前に承認者へ催促が届きます。
- `期限内に終わる`：どのチケットも 93 営業日のうちに終わります。長くても 93 営業日です。

## 経路の例

検査は、経路がどの例にも、横に書いたステップを与えることを確かめています。

| 種別 | 合計 | 経路 |

| 出張 | 30,001円 | 上長（決裁） |
