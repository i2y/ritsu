# 便の判定 v1

規則をローカルアクティビティで呼ぶ（Temporal）：注文ごとに規則で便を決めて知らせる。規則のタイムアウトを処理してタスクを呼ぶ呼び出しと、ふつうのアクティビティで呼ぶ規則も通る。ほかのプラットフォームでは、ふつうの規則の呼び出しと同じ

`tests/flows/local_rules.flow` を `dandori doc` で描いたものです。入力は `注文: list[注文]`, `まとめ: 注文` です。
