sekisho check — check the words, the names and the types, and every combination the file declares

Usage:
  sekisho check <file.gate>... [--format json] [--budget <n>]

Arguments:
  <file.gate>...  the .gate files to check

Flags:
  --format json  one JSON object a file
  --budget <n>   the most combinations the check walks for one action (default 100000000)
  --lang ja|en   the language of the text; else the SEKISHO_LANG environment variable, then RITSU_LANG, else en (default en)
  --help         print this page

Exit codes:
  0  no errors (there may be warnings)
  1  at least one error
  2  bad arguments, a file that cannot be read, or a file that reads a rule, a dates file, a calendar, a book or a flow, run with this sekisho, which reads none of them (E209: run it as ritsu sekisho)

Examples:
  $ sekisho check shop.gate
  $ ritsu sekisho check examples/refunds/refunds.gate --format json --lang ja
