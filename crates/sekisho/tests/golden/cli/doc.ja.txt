sekisho doc — 人が読むページを出す。action ごとの表、ポリシーと生成する Cedar、計算した値とその規則と日付のページ、期待と役割、ワークフロー、守る操作

使い方:
  sekisho doc <file.gate> [--format markdown|html] [--root <dir>] [--lang ja|en]

引数:
  <file.gate>  検査を通る .gate のファイル

フラグ:
  --format markdown|html  ページの形。html は外のファイルを読まない一枚の HTML（明るい配色と暗い配色）。規則と日付のページは、Markdown では畳んだ節に入り、HTML ではボタンからページの上に開く（既定 markdown）
  --root <dir>            参照のパスを数えるルート。無ければ、最初に渡したパスの上で .git を持つ一番近いディレクトリ（それも無ければ、そのファイルのあるディレクトリ）
  --lang ja|en            文面の言語。無ければ環境変数 SEKISHO_LANG、次に RITSU_LANG、どちらも無ければ en（既定 en）
  --help                  この画面を出す

exit code:
  0  出した
  1  ファイルが検査を通らない
  2  引数の誤り、読めないファイル、ほかの言語を読むファイルを、それを読めないこの sekisho で走らせた（E209）

例:
  $ ritsu sekisho doc examples/refunds/refunds.gate --root examples/refunds > refunds.md
  $ ritsu sekisho doc examples/refunds/refunds.ja.gate --root examples/refunds --format html --lang ja > refunds.ja.html
