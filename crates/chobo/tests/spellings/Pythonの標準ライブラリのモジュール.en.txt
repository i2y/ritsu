  = Python (`--target python --books postgres|tigerbeetle|mysql`): the client is the module `site.py`, and Python's standard library has a module `site` too. Python keeps one module per name, and `import site` gives the one imported first: once the standard library's `site` is imported, the client cannot be imported; imported before it, the client is what every `import site` in the program gets in place of the standard library's. A package of `ritsu gen` holds the module as `<package>.books.site`, which does not meet the standard library's.
  hint: For a target you do not build, leave it as it is. For one you do, rename it; if the book is in use, check the renamed book against the revision in use with `chobo check --diff-base`.
