  = PostgreSQL（`postgres`、`postgres-typescript`、`postgres-python`、`postgres-go`、`postgres-rust`）: SQL は、振替の操作を `<振替>_<操作>`、勘定の残高を `balance_<勘定>` という関数にするので、勘定 `注文_hold` の残高の関数と振替 `balance_注文` の `hold` の関数は、どちらも `balance_注文_hold` です。PostgreSQL は同じ名前の関数を引数の型で分けますが、この二つは引数の型も同じなので、SQL のファイルを読み込めません（二つ目で `cannot change return type of existing function`）。
