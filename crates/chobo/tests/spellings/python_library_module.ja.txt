  = Python（`--target python --books postgres|tigerbeetle|mysql`）: クライアントはモジュール `abc.py` で、Python の標準ライブラリにもモジュール `abc` があります。Python は同じ名前のモジュールを一つしか読み込まず、`import abc` は先に読み込んだほうを返すので、標準ライブラリの `abc` を読み込んだあとでは、クライアントを読み込めません。先にクライアントを読み込むと、プログラムのどの `import abc` も、標準ライブラリのものの代わりにクライアントを返します。`ritsu gen` のパッケージは、このモジュールを `<パッケージ>.books.abc` として持つので、標準ライブラリのものとぶつかりません。
