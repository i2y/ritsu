    11 | transfer receive(delivery: string, lot_K: string, lot_K: string, sku: string, qty: pcs)
  = Python（`--target python --books postgres|tigerbeetle|mysql`）: Python は識別子を NFKC にしてから比べるので、`lot_K` と `lot_K` は同じ識別子です（U+212A と U+004B の字が違います）。`_receiveTransfer` のメソッドに同じ名前の引数 `lot_K` が二つでき、モジュールを読み込めません（`SyntaxError`）。
  = Rust（`--target rust --books postgres|tigerbeetle|mysql`）: Rust は識別子を NFC にしてから比べるので、`lot_K` と `lot_K` は同じ識別子です（U+212A と U+004B の字が違います）。`ReceiveArgs` のフィールド `lot_K` を二度宣言することになり、コンパイルできません。
  ヒント: 使わないターゲットなら、このままで構いません。使うなら、どちらかの名前を変えてください。すでに使っている帳簿なら、名前を変えたあと、使っているリビジョンと `chobo check --diff-base` で比べてください。
