## E102 — 出典が固定されていません

**いつ出るか**: 表の出典の行か、法令の条の固定の行に `sha256:` が無いとき。

**直し方**: コピーの SHA-256 の先頭 16 桁を `sha256:` で書きます（直し方に、いまのコピーの値を書いた行が出ます）。

**再現**:

```cal
calendar t v1

source 休み = file "holidays.csv"
  format csv
  covers 2026-01-01..2026-12-31

closed 休み
```

`holidays.csv`:

```
2026-01-01,元日
2026-05-04,みどりの日
```
