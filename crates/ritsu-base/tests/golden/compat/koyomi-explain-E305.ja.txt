E305 (エラー) — 検査の予算を超えました（確かめていません）

いつ出るか: 入力の組み合わせの数（日付の範囲の日数と、整数の入力の範囲の大きさの積）が予算を超えるとき。一部だけ試して通すことはしません。

直し方: 範囲を狭めるか、ファイルを分けるか、`--budget` で予算を上げます。

再現:
    dates t v1
    
    inputs
      d : date  range >=0001-01-01 <=9999-12-31
      n : int   range >=1 <=100
    
    date x = d
      + n days
